|---|---|

| 動畫 | 每個動畫一張分鏡（開始、關鍵影格、結束）、一個 GIF、一張「減少動態」版本 |

| 文案 | 圖上的文字就是提案文案。沿用 `strings.dart` 的，標 key；新寫的，標「新」，核准後由 cow-app 加進 `strings.dart` |
| 假資料 | 牧場名只用詞庫 `backend/server/data/ranch_words.json` 的詞（3 組各 12 個兩字詞，接起來固定 6 個字，例「晨光河畔牧場」），別人的牧場名後面加「#1234」；不用真實姓名。倒數與時間一律寫真實時間（正式版不加速），不出現原型的「遊戲時間、倍率」 |
| 進 git | 加標籤的圖用 DPR 2；DPR 3 原始截圖不進 git，靠 harness 重產；核准版整套附在 GitHub Release（照 ceo 之前的決定） |

**類型**
- 「整頁」：一整個手機畫面。430、390 各一張。
- 「局部」：只差在一小塊的狀態，例如按鈕停用、標籤、提示條。好幾個狀態並排在一張「狀態表」上，一樣出 430、390 各一張。
