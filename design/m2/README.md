   - 顏色看 `src/css/base.css`、`kit.css`、`screens.css` 和匯出的 SVG 原檔（`app/assets/`、`src/js/icons.js`）。
   - 要比顏色時，看重新出圖後 `raw/` 的原色截圖（`harness/capture.mjs`，沒有減色），或直接看原檔。

## 這一版做的設計決定（請特別看）

- 奶桶滿了（S03-02）：產奶的母牛都轉正面，「奶桶滿了」泡泡只放一個（在荷斯坦頭上），免得畫面太亂。第 11 輪的畫面只有荷斯坦轉正面；企劃書 4.2 寫的是「產奶的牛轉正面」。如果要只轉一頭，請說。
- 牧場場景裡的牛換成假資料裡的牛：耕牛（台灣黃牛、高地牛）在田裡工作，所以不在牧場場景裡；多了和牛和娟珊公牛。牛的畫法沒有改。
- 導覽：6 個分頁（牧場、市場、田地、配種、商店、紀錄），設定在頂列右邊的齒輪（ceo 同意）。
- 頂列：牧場名、等級、經驗條（這一級的累積收入進度）、金幣；金幣一百萬以上寫「萬」（窄手機十萬以上）。
- 牧場頁的奶桶卡：寫「約幾分後滿」，而不是每小時產量；滿了寫「滿了，停止產奶」。
- 牛的詳細頁：按鈕固定在下面，資料可以往上捲。
- 還沒發現的品種：圖鑑用深色剪影；配種機率的小圖用淺灰剪影加「？」。
- 出貨：牛跳上小卡車、揮手說「謝謝你的照顧！」，牛肉畫成禮盒，不畫屠宰、不畫肉塊。
- 市場（D24）：一眼看懂。三種商品排成一張卡，顯示「現在的收購價」和「比平常高或低幾 %」，點一列就賣那一種；不畫走勢圖、K 線、成交量。大新聞時牧場頁跳出一次提示（S03-15）。
- 牧場（使用者意見第 3、8 項）：奶桶、倉庫、收購價可以收起來（收起時只剩奶桶一條和收奶鈕）；第一次打開是展開的，之後記住上次的選擇。牧場場景兩個螢幕寬，可以左右滑動；牛會慢慢走動。
- 取名（D23）：玩家自己打字取名，「幫我想一個」從詞庫填一個；中文最多 8 個字。鍵盤是手機自己的，設計稿畫成灰色方塊。
- 借種費（D26）：系統依公牛的體重和稀有度算，主人只決定要不要上架。
- 設定（D25）：加「語言」（繁體中文、English、ไทย）和「漲跌顏色」。英文、泰文的畫面這一版不畫，等字串表出來再量版面。
- 備份牧場、找回牧場（D22，2026-10-01）：換手機改用綁定 Apple／Google 帳號。
  - 登入按鈕照官方樣式，不套我們的按鈕樣式：Apple 黑底白字、Google 白底細外框，兩顆一樣大、Apple 在上，不用捲動就看得到。
  - 設計稿不自己畫 Apple、Google 的標誌：按鈕左邊的虛線方塊是標誌的位置，圖的標題下面有橘色的註解；實作時用官方的登入按鈕，字和標誌以官方的為準。
  - Android 版沒有 Apple 登入，畫成局部狀態（整頁的手機外框是 iPhone）。
  - 頂列齒輪的小點（G-10）只在還沒備份、也還沒打開過「備份牧場」頁時出現，所以其他畫面的頂列沒有小點。

## 字串表與語言（ceo 2026-10-01 交辦；D25）

- 畫面上玩家看得到的字都在 `i18n/zh-Hant.json`：一層「key → 文字」。英文、泰文是同一套 key 的 `i18n/en.json`、`i18n/th.json`（ceo 依 `docs/i18n/glossary.md` 出）。
- key 的取法：
  - `app/lib/l10n/strings.dart` 已經有的字沿用它的 key，佔位符名稱也跟 strings.dart 的參數一樣（例：`level` 是 `Lv {lv}`、`days` 是 `{d} 天`）。設計稿的字跟 strings.dart 不一樣時，以設計稿為準（PR 裡列出這幾個）。
  - 新的 key 用「畫面.用途」，例：`s02.suggest`、`s13.backup.title`；幾個畫面共用的用 `g.`；錯誤碼的文案是 `err.<錯誤碼>`（`scope.md` 第 7 節）。
  - 24 種牛：`breed.<品種>.name`、`breed.<品種>.intro`，特徵名 `trait.A`–`trait.C`，跟 `src/cow/breeds.js` 一樣（`harness/i18ncheck.mjs` 會檢查）。
  - 新聞標題：`news.<商品>_<漲跌>.<序號>`，跟 `backend/cowecon/params.py` 的 `HEADLINES` 一樣（也會檢查）。
    - 飼料新聞（D35）：商品是飼料代號（`grass`、`hay`、`oats`、`alfalfa`、`corn`、`soy`，`backend/cowecon/params.py` 的 `FEED_IDS`），利多、利空各 2 則，跟同一個檔的 `FEED_HEADLINES` 一樣（也會檢查）。
- 文字裡不放 HTML：要換行的地方寫 `\n`；數字加粗之類的，用佔位符把整段塞進去（例：`期望收入 約 {v} 幣`）。
- 不是 app 的字、不翻譯：狀態名稱、橘色註解、動畫分鏡的說明、「手機一個畫面到這裡」、「系統鍵盤（不畫）」、錯誤碼表的錯誤碼；頁面上標 `data-note`。語言選單裡的「繁體中文／English／ไทย」每種語言都用自己的文字寫，標 `data-keep`。
- 玩家取的牧場名、電腦牧場的名字是資料，不在字串表裡。
- 看別的語言：網址加 `&lang=en` 或 `&lang=th`。缺的 key 用繁中顯示，記在 `window.__i18n.missing()`，量測報告會列出來。泰文的字型是 Noto Sans Thai（接在中文字型後面：英文字母、數字跟繁中一樣），用 app 內建的可變字型檔 `app/assets/fonts/NotoSansThai-VF.ttf`（`src/css/base.css` 的 `@font-face`；`harness/server.mjs` 的 `/app-fonts/` 給檔案，cow-app #120，2026-10-03）。電腦的 Noto Sans Thai 只有 Regular、Bold，標 900 的泰文會畫成 Bold，寬度跟手機上不一樣；要用 harness 的伺服器開設計稿，泰文量測才準（量測 JSON 的 `fonts.thaiVf` 要是 `loaded`）。
- 數字縮寫：繁中用「萬」「億」；英文、泰文用 K、M（`Intl.NumberFormat` 的 compact）。
- 給 cow-app 的 strings.dart 對照表、錯誤碼文案、「幫我想一個」的取名詞庫（`namegen.*`）、電腦牧場名的做法：`i18n/README.md`。
- **改了 `i18n/` 的任何一個字串表，同一個 PR 要重產 app 的 `app/lib/l10n/gen/strings.g.dart`**：在 `app/` 跑 `dart run tool/gen_l10n.dart`（照記憶體規則用 systemd-run 包起來）。app 的 `test/l10n_test.dart` 會比對，沒重產 CI 會紅。除了 `app/assets/` 的匯出素材（`harness/assetexport.mjs` 產生，見下一節）以外，這是 cow-ui 唯一會改的 app 檔案（ceo 2026-10-02）。

## 重新出圖

新電腦第一次出圖之前（2026-10-08 換電腦時整理）：

- **字型**：要有 Noto Sans CJK 的 Regular、Bold、Black、Medium（設計稿大量用字重 900，靠 Black）。Ubuntu 預設只有 Regular、Bold。
  - 有 sudo：`sudo apt install fonts-noto-cjk-extra`。
  - 沒有 sudo：從 Google 官方的 noto-cjk 下載 `Sans/OTC/NotoSansCJK-Black.ttc`、`NotoSansCJK-Medium.ttc`，放到 `~/.local/share/fonts/noto-cjk/`，再 `fc-cache -f`。
  - `harness/browser.mjs` 開瀏覽器前會檢查，少了 Black 就停下來，不會拍出別的字重。
