1. 先看 `boards/M2-00-00-全部畫面-總覽.png`：每個畫面的第一個狀態。

   - 標題下面橘色的「註：…」是給看圖的人的說明，不是畫面上的字。
4. 動畫在 `boards/A-動畫/`：每個動畫有 GIF、分鏡圖（每一格寫時間和發生什麼）、減少動態圖（手機開了「減少動態」時的做法）。

## 量測

- 每個狀態在 430、390、360、320 四種寬度量過：最小字級、文字被切掉或超出框、不該換行、重疊、按鈕小於 44×44、擋到狀態列或 Home 指示條、橫向捲動。
- 結果（158 個狀態）：430、390、360 全部沒有問題，最小字級 12 px；320 有 6 個狀態有小問題（寫在 `measure/summary.md`，實作時處理）。
- 320 寬的手機（例如第一代 iPhone SE）很少見；這些只量測，不送核准。

## 這一版做的設計決定（請特別看）

- 奶桶滿了（S03-02）：三頭產奶的母牛都轉正面，「奶桶滿了」泡泡只放一個（在荷斯坦頭上），免得畫面太亂。第 11 輪的畫面只有荷斯坦轉正面；企劃書 4.2 寫的是「產奶的牛轉正面」。如果要只轉一頭，請說。
- 牧場場景裡的牛換成假資料裡的牛：耕牛（台灣黃牛、高地牛）在田裡工作，所以不在牧場場景裡；多了和牛和娟珊公牛。牛的畫法沒有改。
- 導覽：6 個分頁（牧場、市場、田地、配種、商店、紀錄），設定在頂列右邊的齒輪（ceo 同意）。
- 頂列：牧場名、等級、經驗條（這一級的累積收入進度）、金幣；金幣一百萬以上寫「萬」（窄手機十萬以上）。
- 牧場頁的奶桶卡：寫「約幾分後滿」，而不是每小時產量；滿了寫「滿了，停止產奶」。
- 牛的詳細頁：按鈕固定在下面，資料可以往上捲。
- 還沒發現的品種：圖鑑用深色剪影；配種機率的小圖用淺灰剪影加「？」。
- 出貨：牛跳上小卡車、揮手說「謝謝你的照顧！」，牛肉畫成禮盒，不畫屠宰、不畫肉塊。
- 市場：每種商品只有一個市價（D20），品質用倍數乘；「7 天」和「K 線」Lv3 才開放。
- 備份牧場、找回牧場（D22，2026-10-01）：換手機改用綁定 Apple／Google 帳號。
  - 登入按鈕照官方樣式，不套我們的按鈕樣式：Apple 黑底白字、Google 白底細外框，兩顆一樣大、Apple 在上，不用捲動就看得到。
  - 設計稿不自己畫 Apple、Google 的標誌：按鈕左邊的虛線方塊是標誌的位置，圖的標題下面有橘色的註解；實作時用官方的登入按鈕，字和標誌以官方的為準。
  - Android 版沒有 Apple 登入，畫成局部狀態（整頁的手機外框是 iPhone）。
  - 頂列齒輪的小點（G-10）只在還沒備份、也還沒打開過「備份牧場」頁時出現，所以其他畫面的頂列沒有小點。

## 假資料與還沒定的東西

- 遊戲名「牛市牧場」是暫名（D21：上架前再定），做成一個字串，正式名稱定案後替換。
- 牧場名只用詞庫的詞（`backend/server/data/ranch_words.json`），例如「晨光河畔牧場 #1234」。
- 數字照企劃書第 5 節（牛奶 12 幣／瓶、牛肉 12 幣／公斤、稻米 5 幣／公斤等）。時間一律是真實時間。
- 品種的一句話介紹在 `src/cow/breeds.js` 的 `INTRO`，ceo 2026-10-01 審過（牛奶照稀有度叫，例如「傳說牛奶」；圖鑑介紹不提牛肉）。
- 圖鑑全收集：只在圖鑑榜上顯示完成，不給遊戲幣和裝飾（ceo 2026-10-01）。
- 備份牧場的假資料：綁定日期 2026/10/01；另一個牧場用「青草小丘農莊 #5678」（詞庫裡的詞）；畫面不顯示 email 和姓名。

## 重新出圖

```bash
cd design/m2
PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1 npm ci
node harness/cowcheck.mjs            # 第 11 輪定案的牛，SVG 必須一個字都不差
free -m                              # available 要 2000 MB 以上
systemd-run --user --scope -q -p MemoryMax=1500M -p MemorySwapMax=0 node harness/capture.mjs all 430,390,360,320
systemd-run --user --scope -q -p MemoryMax=1500M -p MemorySwapMax=0 node harness/anim.mjs
python3 harness/compose.py && python3 harness/compose_anim.py && python3 harness/summary.py
```

- `raw/`（DPR 3 原始截圖、量測 JSON、動畫影格）不進 git，用上面的指令重產。
- `boards/` 是加了標籤的設計稿（DPR 2，256 色），進 git。
