使用者核准的設計稿才是有約束力的規格。這份文件只是摘要：文字和設計稿不一致時，以設計稿為準，再回頭修正這份文件。

## 第 1 輪：美術風格（2026-09-30）

- 設計稿：`design/artboards/round1/`
- 裁示（2026-09-30，原話）：「選a 但我不喜歡牛的樣子 要給我另外的設計」
  - 整體畫風採用 **A 圓潤Q版**：粗圓可可色描邊、扁平粉彩、胖嘟嘟比例，UI 元件照 R1-A。
  - **牛的造型不採用**，第 2 輪重新提案。
- 延續的規則：牛一律由參數化產生器畫出，由基因決定長相，能量產幾十種品種。
- 補充裁示（2026-09-30，看過 R1 的牛與產生器圖庫 `raw/gallery-a.png` 之後，原話）：「牛眼睛很奇怪，而且每一隻都長一樣體型，我不喜歡。請在給我三個新版本參考」

## 第 3 輪：五種新畫風（2026-09-30）

- 設計稿：`design/artboards/round3/`
  - A 水彩繪本
  - B 剪紙拼貼
  - C 扁平幾何
  - D 復古農場海報
  - E 日系手帳線稿
  - 總覽另有 0 現況：R2-C 的牛放在 R1-A 畫風裡。
- 裁示（2026-09-30，原話）：「原本的風格比較好，我知道問題在哪裡了，牛的外型怪怪的，你重新設計一下，一樣給我五種外型，然後或許可以參考胖胖的可愛的牛。你的牛的外型要改。」
  - **整體畫風改回 R1-A 圓潤Q版**：粗圓可可色描邊、扁平粉彩，UI 元件照 R1-A。取代第 2 輪「A 不再採用」的裁示。
    - 「原本的風格」解讀為 R1-A：使用者看過的畫風裡，第 3 輪之前只有這一種；總覽最左邊的 0 現況用的也是這一種。
  - 第 3 輪五種畫風（A–E）**都不採用**。
  - **牛的外型整個重新設計**：
    - 第 2 輪「牛走 C 側面輪廓」的方向取消。頭朝哪邊變成第 4 輪要比較的選項之一，不再是規定。
    - 第 4 輪（`design/artboards/round4/`）出五種牛的外型，參考「胖胖的、可愛的牛」。
  - 小牛：使用者沒有提到，照「沒提到就是同意」，沿用第 3 輪的比例。
    - 身高約成牛的 55–60%，身體短而圓，腿有肉。
    - 第 4 輪五種外型的小牛都照這個比例畫。
- 第 4 輪每種外型都要做到的事：
  - 修掉 R1-A 牛被否決的地方：眼睛不用直立的橢圓；口鼻不用粉紅大圓鼻，以免看起來像豬；每個品種的體型要明顯不同。（**第 4 輪更正**：「像豬」不是使用者說的，是第 2 輪 README 自己加的；使用者的參考圖有粉紅寬口鼻，見下）
  - 不用 R2-A 的兩頭身大頭。（**第 4 輪更正**：參考圖的頭大約和身體一樣高，見下）
  - 品種、體型、公母、角照企劃書 4.5（main 7d03d46）：
    - 用途分乳用、兼用、肉用。
    - 特徵 A 長毛：更低、更寬。
    - 特徵 B 淡色：骨架小一號、臉短、眼大、單一淡暖色。
    - 特徵 C 光澤：肌肉多一點；肉用加霜降紋。
    - 公牛大一號、肩峰和脖子較粗、沒有乳房。
    - 肉用無角，兼用＋A 長角，其他短角，小牛只有角芽。

  - 參考圖：使用者下載的 `~/Downloads/cow-20260930T040143Z-1-001.zip`，裡面有 5 張（`IMG_9966`–`IMG_9970`）。
    - **這 5 張是有浮水印的圖庫圖片（PIXTA、616pic、pngtree）**：只參考風格，不描圖、不照抄構圖，也不放進 repo、設計稿或 PR。
  - 5 張的內容（用文字記錄）：
    - 9966：手繪細咖啡色線；身體側面、臉朝正面，頭和身體連成一體；小點眼；下半臉一條淺橘色寬口鼻；幾塊大斑；短腿、有顏色的蹄。
    - 9967：黑色塗鴉線稿；坐著、正面；粉紅寬口鼻加小點鼻孔；小點眼。
    - 9968：沒有描邊的扁平色塊；坐著、斜側；很大的粉紅口鼻；咖啡色大斑；黑蹄。

  - 5 張的共同點（第 5 輪依據，只參考風格）：
    - 臉朝玩家（正面或斜側）。
    - 頭很大、跟身體連成一體，沒有脖子。
    - 小點眼、兩眼分得開，沒有大反光。
    - 下半臉一整條寬口鼻（粉紅、淺橘或奶油色都可以），鼻孔是小點或乾脆不畫。
    - 少數幾塊大斑。
    - 腿很短。
    - 平塗、沒有陰影或亮面。
    - 線比 R1-A 細，有手繪感。
    - 沒有牛鈴，乳房之類的細節很少。
  - 更正前幾輪自己加的限制：
    - 「粉紅大圓鼻像豬」不是使用者的話（出自 `round2/README.md`）。改成：寬口鼻橫跨下半臉，粉紅或淺橘都可以。

    - 「側面至少兩種」取消：5 張參考圖都是正面或斜側的臉。
  - 仍然有效：
    - 每個品種的體型要明顯不同（使用者 R1 的意見）。
    - 小牛約成牛 55–60% 高。
    - 牛由參數化產生器依基因畫出。
