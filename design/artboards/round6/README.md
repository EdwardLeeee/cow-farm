## 牛（產生器 `src/shapes/r6.js`）

- 線條：B 乾淨中線，線寬 2.4 模型單位、`#4B3326`、輪廓平滑。
- 側面（9966 構圖）：身體橫著、背往屁股稍微往下；頭立在身體前端、頭頂略高過背、下緣約在身體 70–75% 深；短腿分兩對、走路時一前一後；少數大斑；小乳房。
- 正面（9967 構圖）：頭在上、跟身體頂端重疊；梨形身體上窄下寬（公牛肩膀寬）；耳朵往兩側橫伸；角往上彎（高地牛的長角往兩側大大展開）；斑在胸口和肚子。
- 品種、公母、小牛、角照企劃書 4.5：乳用高而窄、肉用寬而矮、娟珊小一號、高地牛長毛有瀏海、公牛大一號、小牛約成牛 56–59% 高。
