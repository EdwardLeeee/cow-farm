## 照三點改了什麼

1. **小牛各跑各的**：每頭照自己的路線跑，會轉彎、突然改方向、停一下，彼此分得開。閃閃發亮的那頭比較可能是稀有。
2. **真的可能抓不到**：一局 3 個繩圈（提案），右上角看得到還剩幾個。抓不到有三種：
   - 丟偏了：繩圈落在草地上，拉回來，用掉一個。
   - 被牠閃掉：繩圈還在飛，小牛突然轉彎跑開，也用掉一個。
   - 沒拉滿就掙脫：套到以後要連點把條拉滿；小牛一直往外扯，條會往回掉，掉回 0 就掙脫。
   - 3 個繩圈用完就是「跑掉了…」，這一局用掉一次機會。每天 3 次照舊。
3. **繩子綁在小牛身上**：繩圈落下以後縮緊成一圈，綁在脖子上（有一個結），繩子從脖子拉到畫面下緣。拔河的時候繩子拉直、繃緊（中間兩條白色的緊繃記號），跟著小牛動。
