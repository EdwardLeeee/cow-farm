- **日期**：2026-10-09（cow-ui，ceo 交辦）
- **依據**：使用者看完第 23 輪（ceo 2026-10-09 轉達）：
  - 01 丟飼料：「不用顯示近遠，然後飼料拉出去不用有圓圈底」。
  - 02 飼料列：「b比較好，但我想看看沒有背景然後放在奶桶上方的ui比較」。
  - 03 倉庫：「B 面板倉庫小鈕」（定案，這一輪每一張都用）。
  - 04 圖示：「a比較好，但我傾向於肚子餓才會顯示，不過這個飢餓顯示圖樣可以給我看幾種不同的樣子」。
- **狀態**：草稿，等使用者挑。02 選有底板或沒有底板；04 選 A–D 其中一種。

## 改了什麼

- **01 丟飼料**：拿掉「近」「遠」的虛線和標籤；拖曳時只有飼料本身，底下沒有圓圈；落地改成揚起一點灰塵。肚子餓的牛頭上有圖示，吃完就不見。
- **02 飼料列 B**：兩版並排。
  - 原本：在奶桶面板下面，白色底板，左右滑。
  - 沒有底板：袋子直接浮在牧場上，緊貼在奶桶面板上方，「倉庫」「收起」那排在袋子上面；字加白邊。
- **03 倉庫**：用面板左上角的「倉庫」小鈕（B）。
- **04 肚子餓的圖示**：只有肚子餓、現在可以吃的牛頭上才有；吃飽冷卻中的、長到最壯的都不顯示。從第 23 輪 A 的碗畫四種：
  - A 空碗加問號
  - B 空碗冒抖動的線
  - C 碗加飼料的泡泡
  - D 舔嘴巴的泡泡
  - 每種都有一個牧場 10 頭都餓了的畫面（成牛吃飽要等 4 小時，常常一大片都在餓）。
