## cow-ui 的提案和注意事項

- **特殊牛的記號**：用金色膠囊加寶石，寫「特殊」。沒有用 ceo 舉例的「金色光圈」，因為光圈很像宗教畫裡的光環。
- **不畫宗教符號**：
  - 宙斯牛：閃電紋、金色的角。
  - 青牛：祥雲只當花紋。
  - 聖白牛：金色捲紋，額頭不加記號。
  - 三種都不畫光環、蓮花、太極這類圖案（Apple 1.1.1）。
- **套圈圈要跟別的遊戲不一樣（Apple 4.1）**：小牛站在草墊上不動，比的是瞄準和力道（往後拉的長度），畫面是台灣夜市的套圈圈攤位。不做「甩繩子套追著跑的動物」。
- **產生器**（`design/m2/src/cow/r11.js` 的 `paintSpecial`、`breeds.js` 的 `genesFor`）：
  - 加了特殊牛的花紋（閃電、祥雲、金色捲紋）、可以指定角的顏色和種類。
  - 24 種牛和雜種牛都沒有用到，畫出來完全一樣（cowcheck 103/103）。
  - 特殊牛的基因定義只在草稿（`src/r15.js` 的 `SPECIAL`），使用者核准以後才搬進 `breeds.js`、匯出素材。
- **配種表的配法是假資料**：每個品種列哪幾個代表配法，由伺服器的資料表定。
- 稀有度在 01、03、04 先用 02-A 或原本的標籤畫，照使用者選的星星換。
