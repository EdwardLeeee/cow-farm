## 這一輪改了什麼（和第 9 輪比）

| | 第 9 輪 | 第 10 輪 |
|---|---|---|
| 側面乳房 | 有 | 拿掉 |
| 正面乳房 | 肚子上，四個奶頭從下緣垂下來 | 位置不變；奶頭畫在乳房上（A）或貼在下緣（B） |
| 正面臉長 | 高÷寬 1.25 | 1.1 |
| 和牛 | 黑色加淡色細點（看起來髒） | 拿掉細點；A 黑亮／B 深紅棕亮毛／C 黑亮加短角 |
| C 光澤 | 霜降紋 | 一道乾淨的白色亮光（側面在背上、正面在額頭；淺色的毛看不出來就不畫） |
| 黑牛的線條 | 深咖啡色線在黑毛上看不見 | A 線條改成 `#9A8783`（毛不變）／B 毛改炭灰、線條改 `#1C1311` |
