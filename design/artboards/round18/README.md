## 檔案

每版一張 5 格分鏡：1 開始前的說明、2 玩的時候、3 丟出去、4 套到以後、5 抓到了。

| 檔名 | 項目與選項 | 玩法 | 好玩在哪裡、手感 |
|---|---|---|---|
| `R18-01-抓牛小遊戲-A-一群一起跑-390.png` | 01 A 從上往下看、一群一起跑 | 六頭小牛一起往右跑；手指從下面的繩圈往一頭小牛前面一點滑，繩圈飛出去；套到以後連點畫面拉繩子，上面的條拉滿就抓到 | 從一群裡挑閃閃發亮的那頭、算好提前量（像打移動靶）；一滑就丟很直覺，最後連點拔河很過癮 |
| `R18-01-抓牛小遊戲-B-側面衝過來-390.png` | 01 B 側面捲動、一頭一頭衝過來 | 側面看，畫面往右捲；小牛一頭一頭從右邊衝過來；按住甩繩圈，小牛跑到中間的白色記號下面時放開；套到以後小牛左右拉，手指往反方向拖，讓指針停在綠色 | 像節奏遊戲，抓準那一刻；拔河要跟著牠換方向，比較需要專心 |
| `R18-01-抓牛小遊戲-C-往前看衝過來-390.png` | 01 C 往前看、從遠處衝向你 | 透視的原野，小牛從地平線朝你衝過來、越來越大；腳踩進地上的白色虛線圈時往上滑；套到以後照著「拉！」和上面的節奏點往下拉，停的時候放手 | 越衝越大很有臨場感，太早太晚都不行；拉的時候像打拍子 |
| `R18-01-抓牛小遊戲-D-草叢畫一圈-390.png` | 01 D 草叢捉迷藏、畫一圈 | 從上往下看，小牛躲在草叢後面（草叢會搖、露出耳朵），冒出來時用手指在牠周圍畫一圈，繩圈就飛過去套住；不拔河 | 像打地鼠加畫畫，猜下一頭從哪裡冒出來；不用算力道，一局最短、最輕鬆 |
| `R18-99-總覽對照.png` | 總覽 | A～D 各三格（玩的時候、丟出去、套到以後）並排，最下面一格是特殊牛（金光、橫幅）的例子 | |

## GIF（使用者喜歡 A 和 C）

使用者看完第 18 輪的回答（ceo 2026-10-08 轉達）：「i like A AND c,so you can show me gif」。A、C 各做一個 GIF，看動起來的手感再決定。

| 檔名 | 內容 |
|---|---|
| `R18-01-抓牛小遊戲-A-一群一起跑-390.gif` | 一群小牛往右跑（閃閃發亮的那頭比較可能是稀有）→ 手指從下面的繩圈往牠前面一點滑 → 繩圈飛出去套住 → 連點拔河（每點一下條往上跳，小牛會扯回去一點）→ 抓到了 |
| `R18-01-抓牛小遊戲-C-往前看衝過來-390.gif` | 小牛從地平線衝過來、越來越大 → 腳踩進地上的圈時圈變黃 → 手指往上滑 → 繩圈飛過去套在脖子上 → 照「拉！」往下拖、「停」的時候放開，一拍一拍拉近 → 抓到了 |

- 兩個 GIF 用同一條時間線，方便比較：8 秒、15 格／秒，寬 390，一直循環。
  - 0–2 秒：小牛跑。
  - 1.8–2.2 秒：手指滑。
  - 2.2–2.7 秒：繩圈飛出去。
  - 2.9–6.1 秒：拔河或拉。
  - 6.1–8 秒：抓到了。
- 手指的位置和動作都畫出來：A 是一滑、連點（點一下有波紋）；C 是往上滑、往下拖（拖的時候有箭頭）。
- 程式在 `src/r18.js` 的「第 18 輪 GIF」那一段；出 GIF：`bash ../../../scripts/heavy.sh node harness/gif.mjs`（影格放 `raw/gif-A`、`raw/gif-C`，不進 git）。
