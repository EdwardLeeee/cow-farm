## 五處怎麼改

| 使用者的話 | 怎麼改 |
|---|---|
| 牛身體應該要有曲線，不是橢圓形 | 側面：身體由控制點連成有曲線的外框（背微凹、乳用腰角、圓屁股接到後腿、肚子在前後腿之間往上收、胸口接到前腿），近側兩條腿和身體連成同一條外框、中間沒有分界線。正面：肩膀、身體兩側，底部兩邊有坐下時鼓起的大腿（加一道弧線表示大腿），兩腿中間往上收 |
| 正面的臉應該是垂直方向比較長 | 臉的寬度不變、只加高，往下巴收窄；三種長度見項目 02 |
| 母牛正面應該有牛奶頭 | 成年母牛正面：兩條大腿中間露出粉紅乳房和四個奶頭；肉用小一點；公牛、小牛沒有 |
| 尾巴太長 | 尾巴短到身體一半高 |
| 側面的奶頭看不出來，要嘛拿掉要嘛讓人看出來 | 選「畫清楚」：肚子下掛著粉紅乳房和兩個往下的奶頭。理由：正面也要有奶頭，兩個角度一致，玩家才分得出公牛和母牛。使用者也可以改選拿掉，產生器只要關掉一個開關 |

沒被提到的照第 7 輪：側面的臉與比例、正面坐姿、月牙角、圓頭微垂的耳朵、圓形耳標、斑點排列、配色。
