## 三個版本共同做到的事

- **眼睛重新設計**（不沿用 R1 的直橢圓黑眼），三個版本各用一種眼睛，臉部配置一起重排：
  - A：大而圓的亮面眼，深褐虹膜、黑瞳、兩個反光點，眼距寬、放在臉的中線附近。
  - B：溫和的杏仁眼、一個反光點，成年母牛外眼角有兩根短睫毛；娟珊有淡淡的深色眼圈。
  - C：豆豆眼加一個小反光（側面只看得到一隻眼）。
- **口鼻改小**：奶油色／淺米色的寬扁橢圓（荷斯坦、草莓牛用很淺的粉米色），上緣兩個小鼻孔，下面一條小嘴；不再是大圓粉紅鼻。
- **像牛不像豬**：耳朵往兩側橫伸、每頭都有角或角芽、尾巴末端一撮毛、深色的蹄、成年母牛有小乳房、每頭戴牛鈴項圈（三個版本統一採用）。
- **草莓牛**：奶油白底、草莓紅斑塊、斑上有淡色籽點、頭頂綠葉蒂頭。**巧克力牛**：咖啡底加奶油色斑，維持原設計（頭頂奶油旋）。
- **畫面其他部分照 R1-A 不變**：粗圓可可色描邊、扁平粉彩、UI 元件、假資料都相同（沿用 R1 的 `ui.js`、`style-a.css`、`FARM` 與站位）。

## 體型由基因決定（產生器照樣能量產）

流程：**基因 → `src/plan.js` 體型參數 → 版本比例 → `src/shapes/cow.js` 幾何 → Q 版畫筆 `src/shapes/q.js`**。
三個版本共用同一套身體幾何，只差在比例、頭與眼睛的畫法，所以品種差異在每個版本都保留（A 把體型倍率再誇大一點，避免被大頭蓋掉）。

| 品種 | 基因 `build`／其他 | 體型 |
|---|---|---|
| 荷斯坦 | dairy | 高、瘦長、腰角與臀部有稜角、乳房明顯 |
| 娟珊 | petite、`face: short`、`eyes: big`、`eyeRim` | 嬌小、腿細、臉短而略凹、深色大眼 |
| 和牛 | beef | 矮壯、胸深、肌肉厚、脖子粗 |
| 高地牛 | low、`fur: fluffy`、`horns: long` | 腿短身體低、長毛蓬、瀏海快遮住眼睛、長角 |
| 草莓牛 | round、`pattern: strawberry`、`overlay: berry` | 圓潤中等 |
| 巧克力牛 | dual、`overlay: cream` | 兼用、中等偏壯 |
| 荷斯坦小牛 | dairy＋`age: calf` | 頭大、腿相對長、身體短、只有角芽、沒有乳房 |

- 新增的基因欄位：`build`（六種體型）、`face`、`eyeRim`、`seedColor`、`collar`；`horns` 多了 `bud` 角芽。隨機基因還會帶連續微調 `jitter`。
- 剪影（塗黑、同一比例）就在每張圖的右下，用來證明七頭體型不同；0 現況的剪影則幾乎一樣，正好對照使用者的意見。
- `raw/gallery-{a,b,c}.png`：每個版本 24 組隨機基因的圖庫，**給 ceo 檢查量產變化用，不給使用者看**。

### 指令（這台電腦曾經記憶體用光當機，出圖一律照這個做法）

```bash
cd design/artboards/round2
PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1 npm ci
free -m    # available 少於 2000 MB 就先等，不要硬跑
systemd-run --user --scope -q -p MemoryMax=1500M -p MemorySwapMax=0 node harness/capture.mjs   # 一次只開一個瀏覽器
systemd-run --user --scope -q -p MemoryMax=1500M -p MemorySwapMax=0 node harness/compose.mjs
```

遇到 exit 137（超過記憶體上限）就改成一個 job 一個 job 跑（`capture.mjs r2-lineup-b` 這樣帶名稱片段），不要調高上限。
