# R22 設計稿：打掃牛站起來掃地、推車牛換衣服（第 22 輪）

- **日期**：2026-10-09（cow-ui，ceo 交辦）
- **依據**：使用者看完第 20 輪（ceo 2026-10-09 轉達，選擇欄位）：
  - 打掃牛：「三種都不錯，但是咬掃把怪怪的，有辦法讓他站起來掃地嗎？ b還不錯，但是藍圍兜怪怪的要重新設計」。
  - 掃地機：「兩個都有，掃地機器會壞掉。一次買要花錢」；樣子「兩款都不錯」。規則由 ceo 跟 cow-back 定，這一輪不畫掃地機。
- **狀態**：草稿，等使用者挑。
- **站姿怎麼畫**：
  - 頭、毛色、花紋用核准的牛產生器。`src/r11h.js` 是 M2 產生器的複製，只多一個 `headOnly`，只留頭；不給的話跟 M2 一模一樣，M2 本身沒有改。
  - 身體是新畫的 Q 版玩偶站姿：圓滾滾的肚子、淺色的肚子、短短的後腳站著、前腳拿工具，不像真的動物用後腳站。
