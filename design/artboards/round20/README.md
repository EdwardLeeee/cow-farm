# R20 設計稿：打掃牛、大便掃地機（第 20 輪）

- **日期**：2026-10-09（cow-ui，ceo 交辦）
- **依據**：使用者看完雅兒貝德比對圖（ceo 2026-10-09 轉達，選擇欄位）：「你改做成打掃牛，有一隻牛會來打掃。還有作一個大便掃地機給我看看。」
  - 小幫手不做成人，改成「打掃牛」：雇用期間會有一頭牛來牧場清大便。
  - 大便掃地機：使用者想先看看。是取代打掃牛還是另外一個東西，看完圖 ceo 再問。
  - 雅兒貝德的比對圖和程式只留在暫存區，不進 repo。
- **規則**（v0.3 第 5.1 節）：
  - 一天 2,000 幣，最多一次付 7 天。
  - 雇用期間每 30 分鐘把大便全部清掉，牛不會因為大便生病。
  - 掃地機的價錢、規則都寫「待定」。
- **狀態**：草稿，等使用者挑。打掃牛選一種；掃地機先看樣子。
- **畫法**：打掃牛用核准的牛產生器（第 11 輪畫風）加配件（`src/r20.js` 的 `accA`～`accC`），牛本身沒有改，產生器也沒動。原創，不像其他遊戲的吉祥物。
- **右上角**：雇用中把大便數的膠囊換成「打掃中」，左邊是那頭打掃牛的臉，右邊寫還有幾天。這是 M2 S03-26 那時留下來的「還沒改」。

- 打掃牛每張 5 格：
  1. 雇用面板：1／3／7 天，一天 2,000 幣。
  2. 雇好了，右上角變成「打掃中」，打掃牛走進牧場。
  3. 走到大便旁邊。
  4. 清掉：大便不見、冒星星。
  5. 清乾淨了，在旁邊散步。
- 掃地機每張 4 格：購買面板（待定）、在牧場自己跑（虛線是路線）、吸大便（漩渦）、吸完回去充電。
- GIF：每個 5 秒、15 格／秒、寬 390，一直循環。
  - 打掃牛：從左邊走進來，三坨一坨一坨清掉。
  - 掃地機：從充電座出發，一坨一坨吸掉，再回去。
- 牧場裡拿掉了 #7、#12 兩頭牛，讓打掃牛和掃地機走的路看得清楚。
