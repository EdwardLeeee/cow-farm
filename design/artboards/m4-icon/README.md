# M4 app 圖示草稿

- 日期：2026-10-02（cow-ui，ceo 交辦；M4 上 TestFlight 要用）
- 遊戲名稱還沒定（D21），圖示上不放字。照核准的畫風（第 11 輪的牛，D19；M2 設計稿的配色），用牛當主角。
- **結果：使用者選了第 2 輪的 A4 娟珊（決策 D32）。** 實作用的檔案在 `design/m4/icon/`（那裡的 README 寫了哪個檔給哪個平台）。
- 這個資料夾是兩輪草稿的紀錄。沒選的方向只留說明圖，不匯出實作檔。

## 第 1 輪：三個方向

| 選項 | 名稱 | 內容 |
|---|---|---|
| A | 牛臉特寫 | 荷斯坦的大臉，縮到最小也認得出是牛；天空、草地照牧場的配色 |
| B | 山坡上的牛 | 跟啟動畫面（S01）同一個場景：太陽、山坡、荷斯坦坐在草地上 |
| C | 金幣項圈 | 牛的脖子上掛一枚金幣，帶出「賣牛奶、賺金幣」的玩法 |

## 第 2 輪：照 A 的畫法換品種

使用者看過第 1 輪：「a版的最好，但有沒有黃牛版的？我覺得黃牛也很可愛。或是你給我看我們目前的經典牛的a類別頭貼」。照 A（牛臉特寫）的畫法畫 6 個品種。天空、太陽、草地跟 A 一樣，牛臉的中心和大小也一樣，方便比較。

| 選項 | 品種 | 說明 |
|---|---|---|
| A1 | 荷斯坦 | 第 1 輪的 A，當對照 |
| A2 | 台灣黃牛 | 使用者點名；啟動畫面那頭小牛也是黃牛 |
| A3 | 安格斯 | 炭灰黑、沒有角的肉牛 |
| **A4** | **娟珊** | **淺褐色的乳牛，臉短、眼睛大（D32 選這個）** |
| A5 | 台灣水牛 | 深灰色，一對往後彎的大角 |
| A6 | 高地牛 | 薑黃色長毛蓋住眼睛，長長的角 |

- 水牛、高地牛的角比較長：臉跟 A 一樣大時，角尖會超出畫面，也會蓋到太陽。

## 做法

- `src/icon.js` 用 `design/m2/src/cow` 的牛產生器畫 SVG。同一份圖：iOS 用 0–1024 的範圍；Android 把 1024 對到中間看得到的 72dp，外圍多畫一圈到 108dp。
- `harness/make.mjs` 用 Playwright 截圖，在這個資料夾底下跑（用 `design/m2` 的 node_modules 和靜態伺服器）：
  - `node harness/make.mjs 1`、`node harness/make.mjs 2`：出第 1、2 輪的說明圖和總覽。
  - `node harness/make.mjs export A4`：把選定的方向匯出到 `design/m4/icon/`。
  - 照記憶體規則：`free -m` 可用少於 1 GB 就先等，用 `systemd-run --user --scope -q -p MemoryMax=1500M -p MemorySwapMax=0` 包起來。
- 不畫 Apple、Google 的標誌；不沿用其他遊戲的名稱、畫風或畫面配置。
