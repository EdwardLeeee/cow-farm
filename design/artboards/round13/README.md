# R13 設計稿：照顧牧場（v0.3，D35）的方向（第 13 輪）

- **日期**：2026-10-03（cow-ui，ceo 交辦）
- **依據**：企劃 v0.3 `docs/design/v0.3-care.md`（第 1、1.1、5、5.1、11 節），決策 D35 與補充（使用者原話都在 `docs/decisions.md`）。
- **狀態**：草稿，等使用者選。ceo 用網頁給使用者看（從分支 `ui/r13-drafts` 取圖）。
- 每個選項一張圖，左上角印的標籤就是檔名；畫面用 M2 設計稿的元件、牛的產生器和假資料。
- 新的字都是草稿，直接寫在 `src/`，沒有進字串表；使用者選完才收進 M2（新頁面 ID、字串照三步走），英文、泰文那時再翻（D25）。

## 這一輪的範圍（ceo 2026-10-03）

| 項目 | 選項 | 內容 |
|---|---|---|
| 01 打掃小幫手 | 2–3 個造型 | 成年的牧場大姊姊，日系可愛動漫風，牧場工作服；大圖、縮小放進牧場場景撿大便的樣子；每張標預估的 Apple、Google 年齡分級；名字提 2–3 個 |
| 02 小牛 6 種基本款 | 1–2 個方向 | 乳牛、耕牛、肉牛 × 公、母；小時候都長一樣，長大才揭曉品種 |
| 03 雜種牛 | 1–2 個方向 | 三種體型（乳牛、耕牛、肉牛），最基本款、毛色素素的；圖鑑裡另外一格 |
| 04 大便、病牛、清大便 | 1–2 個方向 | 牧場場景的大便、病牛（明顯但不嚇人）、點一下或劃過去清掉的手勢 |
| 05 小牛卡片、想吃泡泡 | 1–2 個方向 | 小牛卡片上「可能長出的特徵、要吃的飼料、吃了沒」；小牛頭上「想吃燕麥」泡泡；快長大的提醒卡 |

- v0.3 第 11 節的其他項目（餵食的畫面、市場的飼料分頁、商店的地板和卡車、雇小幫手、排行榜最高最低價）不在這一輪：使用者選完方向以後，直接收進 M2 設計稿。
