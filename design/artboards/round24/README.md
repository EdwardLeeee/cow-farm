- **狀態**：草稿，等使用者看。

## 怎麼玩

1. **拖**：手指在下面拖，地上一個虛線圈跟著動，標出繩圈會落下的位置。虛線圈在手指上面一點，手指不會擋住。
2. **放開**：繩圈在空中轉著飛 0.7 秒，地上的影子往落點移動。
3. **落下**：那一刻小牛在虛線圈裡就套到；不在圈裡就落空，繩圈平平落在草地上，拉回來，用掉一個。
   - 小牛照第 21 輪各跑各的、會轉彎，所以要往牠「等一下會到」的地方丟。
   - 落空一次，小牛會嚇一跳、跑快一點。
4. **建議**：一局 3 個繩圈、套到就抓到（不拔河）。
   - 好玩的地方在預判。
   - 套到以後小牛往後扯、被拉過來，但一定抓到。
   - 3 個都落空就是「跑掉了…」。

## 繩子怎麼套在小牛身上

- 小牛的頭是正面（第 11 輪的畫法：側面的身體、頭轉過來看玩家），脖子被頭擋住。
- 所以套在脖子上的繩圈，從正面看是下巴下面一條往下彎的繩子，兩端繞到頭後面被頭擋住；快繞過去的地方顏色暗一點。
- 下面打一個結，被拉著收成圓圓的 V；繩子從結拉直到畫面下緣，跟著小牛動。
- 繩子有粗細、一股一股斜斜的編織紋、偏左上的亮光。
- 做法：`src/r11h.js` 是 M2 牛產生器的複製，多一個 `split`，把身體和頭分成兩張，繩子夾在中間（身體 → 繩子 → 頭 → 結）。不給 `split` 的話跟 M2 一模一樣，M2 的產生器沒有改。
