## 先想好姿勢再畫

參考人掃地、鏟東西、推推車的樣子，自己看懂以後重畫，沒有描圖。

- **掃地（A）**：掃把斜斜擋在身體前面。上面的手握柄的上端（胸口、另一邊），下面的手握柄的中間（腰邊、掃把那一邊），掃把頭在腳旁邊的地上。掃的時候上面的手不動，下面的手跟著掃把左右走。
- **鏟（C）**：兩隻手都握在鏟柄上。後面的手握柄尾的 D 形握把（另一邊的腰），前面的手握柄的中間；身體往前傾一點，鏟頭貼著地。水桶放在地上：鏟起來、抬到水桶上面、倒進去。
- **推推車（B3）**：兩隻手各握一根把手（腰的高度），身體往推車那邊傾；遠的那隻手大部分被身體擋住，只露出前臂和手。
- **身體**：梨形的 Q 版身體，頭、毛色、花紋用核准的牛產生器（`src/r11h.js` 是 M2 產生器的複製，只多選項，M2 的沒改）。手臂從肩膀長出來（肩膀的地方沒有一圈線）、手肘往外彎；兩隻腳平平踩在地上，有影子。
- **衣服畫在身上**：
  - B3 吊帶褲用身體的外框裁切：腰線往下彎、兩邊暗一點看得出身體是圓的；吊帶繞過肩膀；有口袋、縫線、皺褶；手臂蓋在吊帶上面；牛仔褲管有反摺。
  - B1 重新設計成像工作犬的背心：披在背上、往兩邊垂下來，用身體的外框裁切；下擺在身體側面一半的地方、順著圓筒形的身體往下彎，下面看得到毛；反光條跟著身體彎；肚帶和扣環；推車的繩子掛在背心後面的環上。
