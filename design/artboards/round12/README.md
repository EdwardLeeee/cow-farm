## cow-ui 的提案（圖上有寫）

- 從哪裡打開「牧場資料」：點頂列的頭像或牧場名；頂列頭像的右下角多一枝小鉛筆，讓人知道可以點（D34 還沒定，ceo 建議點頭像）。
- 換頭像免費、次數不限（ceo 提案）。
- 改名的規則照 D23（中文字算 2、英文字母和數字算 1，總共 2–16；不收表情符號和控制字元），由伺服器檢查；#1234 不會變。
- 超級事件的幅度寫出來（+100%、−90%）；一般新聞、大新聞照現在的樣子，不寫幅度。漲紅跌綠照台灣習慣（英文、泰文照 D25 的設定）。
- 新聞卡右上角已經拿掉「全部是虛構的」（D33，#114）。
