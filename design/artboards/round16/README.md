## cow-ui 的建議

- 02 選 A 紫色：星星很小（圖鑑格子、名片）時，彩虹的顏色擠在一起看不清楚；紫色跟金色、各級的底色都分得開。
- 以前提案的寶石「特殊」記號就不用了，特殊牛也照星星排。
- 套索的手感比的是「時機」（圈的大小在剛好的時候放開）加上瞄準跑動的小牛；畫面是牧場運動會的跑道。跟夜市套圈圈（黃昏、小牛站著不動、比瞄準和力道）、UFO 光束（晚上、按住吸）分得開。
