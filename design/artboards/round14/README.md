## 試畫的做法（`src/anime.js`）

- **線條**：畫成「筆刷」，也就是沿著曲線、寬度會變的填色形狀，兩端收尖。另外疊一層往右下偏一點的深色，所以陰影那一邊的線比較粗。
- **陰影**：每個區塊（皮膚、頭髮、衣服）用 clipPath 疊陰影。
- **眼睛**：虹膜用漸層，加上外圈、瞳孔、三個高光，再疊上眼皮的陰影、睫毛和眼線。
- **頭髮**：一束一束的尖形狀，每一束有自己的陰影和亮光。頭頂另外有一圈亮帶，整頭頭髮上亮下暗。
- 造型 A（試畫用）：蜂蜜金色長髮、綠眼睛、白色泡泡袖露肩上衣、綠色綁帶背心。
