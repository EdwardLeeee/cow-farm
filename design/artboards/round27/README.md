# R27 設計稿：牛仔套索（只有虛線圈、小牛亂跑、更難抓、加回拔河）、背景三種（第 27 輪）

- **依據**：使用者看完第 24 輪（ceo 2026-10-09 轉達）：「可以就是這樣，只是我覺得虛線那邊不要有一條直線，一個圈圈就可以了。然後背景要改一下，這一版覺得改進。另外，牛要隨機滿圖跑。不要這麼好抓」；拔河：「要拔河」。

## 改了什麼

1. **只有虛線圈**：拿掉從下面拉到圈的那條直線，只剩一個虛線圈。手指在圈的下面一點，不會擋住圈。虛線圈白色虛線底下墊一圈半透明深色，蓋在牛或草上都看得清楚。
2. **背景三種（白天）**：跟夜市套圈圈（黃昏）、UFO 光束（晚上）分開。
   - A 遠近的山坡和樹
   - B 柵欄和花叢
   - C 小溪和石頭
3. **小牛滿圖亂跑**：每頭的路線隨機挑整個畫面裡的點，速度每段不一樣，有時跑到一半轉向、有時停一下。
4. **更難抓**：圈變小、小牛變快、落空一次小牛受驚跑更快。數字寫在 R27-01 的「數字（起點）」卡片。
5. **加回拔河**：套到以後連點把條拉滿才抓到；小牛一直往回扯，條掉到 0 就掙脫，用掉一個繩圈。繩子一直繃緊、跟著小牛動。抓到、掙脫兩種結果都畫了。

## 數字（起點，之後再調）

- 虛線圈半徑 28（畫面寬 390；第 24 輪是 36）。
- 繩圈飛 0.7 秒。
- 小牛速度：其他小牛每秒 70–100、要抓的那頭 120–150（畫面上的點）。
- 落空一次：小牛受驚 1.5 秒，速度 ×1.4。
- 拔河：條從 30% 開始，小牛每秒往回扯 25%，連點一下 +9%（一秒點 6 下大約 2.5 秒拉滿）。
- 一局 3 個繩圈，每天 3 次。
