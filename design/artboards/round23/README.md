## 規則（ceo 先定，畫進分鏡）

- 從牧場下面的飼料列拖一份飼料，丟在牧場地上。
- 離落點最近、而且現在能吃的牛走過去吃。吃飽冷卻中的、過了最壯的不會過來，換下一頭最近的。
- 附近沒有能吃的牛：飼料在地上停幾秒、閃一下，再飛回飼料列（倉庫），份數加回去，不會浪費。
- 小牛要吃指定的飼料：丟在那頭小牛旁邊。
