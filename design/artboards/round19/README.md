# R19 設計稿：餵食（第 19 輪）

- **日期**：2026-10-09（cow-ui，ceo 交辦）
- **依據**：v0.3 企劃第 2.2 節：使用者 2026-10-03 選「一頭一頭餵」，另外牧場面板有一顆「全部餵一樣的」，給牛多的時候省事用。
  - 吃飽冷卻：成牛 4 小時、小牛 45 分鐘（遊戲時間）。
  - 過了最壯、上架借種中的公牛不能餵。
  - ceo 2026-10-08 決定先畫草稿給使用者挑。選飼料、「全部餵一樣的」這兩個畫面使用者還沒看過。
- **狀態**：草稿，等使用者挑。每一項選一種；01 選 B（拖飼料）的話，02 不用選。
- 飼料的數字是起點，模擬再調：每次長幾公斤（牧草 +1 … 豆粕 +8）、倉庫的份數。
- 程式在 `src/r19.js`，用 M2 設計稿的元件、集點卡和飼料圖示。新的字是草稿，直接寫在程式裡；使用者選完才加字串、翻英文和泰文。
