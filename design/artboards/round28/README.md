# R28 設計稿：大便掃地機的選款式、壞掉了、修理（第 28 輪）

- **日期**：2026-10-09（cow-ui，ceo 交辦；v0.3 企劃第 5.2、12 節）
- **依據**：使用者選「兩款」：「兩個都有，掃地機器會壞掉。一次買要花錢」。規則照引擎（`backend/cowecon/farm.py` 的 `buy_robot`、`repair_robot`，`params.py` 的 `robot_*`）。
- **狀態**：草稿。使用者已經選了兩款，這一輪沒有 A／B 要選：看完說可以，或說要改哪裡。

## 規則（畫進畫面的）

| | 基本款（乳牛紋圓盤） | 耐用款（透明圓頂） |
|---|---|---|
| 買 | 3,000 幣 | 12,000 幣 |
| 多久清一次 | 每 60 分鐘 | 每 60 分鐘 |
| 多常壞 | 平均 1 天一次 | 平均 3 天一次 |
| 修理 | 750 幣 | 3,000 幣 |

- 數字是起點，引擎重跑完整模擬再定。
- 一次只有一台：買另一款就換掉，舊的收走、不退錢。已經有的那款不能再買（壞了用修理）。
- 什麼時候壞玩家看不到，所以畫面上沒有倒數、沒有耐用度條，只寫「平均幾天壞一次」。
- 壞了就停在原地，大便越積越多；付修理費馬上開始動。
