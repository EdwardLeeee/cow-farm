# 泰文字串表的翻譯備註

- 日期：2026-10-02
- 對象：`design/m2/i18n/th.json`（ceo 交由子代理翻譯，ceo 審過並修改）
- ceo 審查後的修改：見 PR 說明。

1. `appTitle`「ฟาร์มวัวขาขึ้น」是暫名：ขาขึ้น 是泰文說股市「漲勢」的詞，保留「牛市」的雙關。正式泰文名照 D21、D25 在 M4 之前定。
2. `s20.gradeSuffix`「เกรด」：設計稿把小字放在大字母後面，會讀成「A เกรด」。泰文（英文也一樣）要寫「เกรด A」，建議 th、en 把小字移到字母前面。
3. `s12.weeklyHint` 照原文寫台灣時間「วันจันทร์ 00:00 (เวลาไต้หวัน)」。D25 要換算成手機當地時間，這句得加佔位符（在泰國是週日 23:00）。
4. `s13.udNote`：check.py 不收中文字，所以「繁體中文」寫成 ภาษาจีนตัวเต็ม；English、ไทย 寫成 ภาษาอังกฤษ、ภาษาไทย。
5. `s02.widthRule`、`s02.errShort`、`s02.errLong` 改成寫給泰文玩家看：泰文、英文字母和數字算 1，中文字算 2；錯誤提示只說 2–16 個字。
6. `s02.placeholder`、`s02.sameName` 的例子是 ฟาร์มแสงเช้าริมน้ำ，由 namegen 的 third.0＋first.0＋second.1 組成，對應「晨光河畔牧場」，寬度 14。
7. `namegen.*` 直接用同一個資料夾裡的 `namegen-th.json`（README 說取名詞庫由 ceo 選詞），接法 `{third}{first}{second}`。
   用 namewidth.js 算過全部組合，最長是「โรงนมแสงเช้าทุ่งโล่ง」，寬度 16。要再想想的一個：`namegen.first.4` ใบแดง（楓葉）在泰文也是足球的「紅牌」。
8. 存放折價沒有現成的泰文詞：`s05.stored` 寫「สภาพ {pct}%」，`s05.priceNote`、`s06.multBeef`、`s06.multRice` 寫 สภาพการเก็บ（保存狀態）。
9. `s19.segFacility`「設施」寫成 อัปเกรด，跟 `upgradesTitle` 一樣；`s11.coachPenBody` 引用的是「ร้านค้า › อัปเกรด」。
10. `badgeWorking`「工作中」寫成 ไถนาอยู่：只有耕牛會工作，比 ทำงาน 清楚。
11. `s03.expand`、`s03.collapse` 寫成 ขยาย、ย่อ；`s03.expandPen` 寫 ขยายคอก，免得兩個意思不同的 ขยาย 撞在一起。
12. `g.perHourRice`「公斤稻米／時」寫成 กก./ชม.，省掉 ข้าว：旁邊的標籤 ไถนา 已經說明是稻米。
13. `expectedValue` 寫成 คาดว่าจะได้ราว {v} เหรียญ：「รายได้ที่คาดหวัง」會被 ICU 切成 ราย|ได้ที่|…。
14. 接在別的字後面的 key 補了空格（繁中靠全形括號、冒號、句號隔開）：`s03.penFullSuffix`、`s06.lots`、`s12.pullHint` 前面有空格，`s18.ownerLabel`「เจ้าของ: 」後面有空格。
15. `studIncome` 省掉「借種」，只寫 รายได้สะสม {v} เหรียญ：卡片標題已經是 พ่อพันธุ์ของฉัน，而且這一列在 320 寬很擠。
16. iPhone、Android 跟 Apple、Google 一樣保留原文，拉丁字母不會從字中間斷開；`s09.no` 保留 No.{n}（README 把它列為格式類）。
17. `s02.errEmoji` 用 สัญลักษณ์แสดงอารมณ์，不用 อีโมจิ：ICU 會把 อีโมจิ 切成 อี|โม|จิ。
18. 換行（用 Intl.Segmenter 實測）：用詞表規定的字會被切開，照規定沒改，cow-ui 量測時要注意。
    這些字是：คอลเลกชัน、อัปเกรด、สตรอว์เบอร์รี、โฮลสไตน์、เจอร์ซีย์、ไฮแลนด์、แองกัส、ชาโรเลส์、วากิว。
19. 外來字會把前面的泰文一起切錯，例如 เหมือนสตรอว์… 會被切成 เห|มือ|นสต。所以 `breed.strawberry.intro` 讓 สตรอว์เบอร์รี 接在空格後面。
    `s09.hint`、`s17.maxFields`、`s14.elsewhereBody`、`breed.yellow.intro` 也換了說法，避開會切錯的地方。
20. 新聞照意思在地化，沒有加真實名稱：牛肉麵→ก๋วยเตี๋ยวเนื้อ、年節→เทศกาลปีใหม่、颱風→พายุ、公糧→คลังข้าวกลาง、冰品店→ร้านไอศกรีม、超市→ห้าง。
    牛排寫 สเต็ก（ICU 認得的拼法）；「中部」照字面翻成 ภาคกลาง。
21. `anim.beep` 的喇叭聲用 ปี๊น；`anim.thanks` 加了中性的語尾 นะ（不是 ครับ、ค่ะ）。
22. `s14.androidHint` 多寫了 ในเกม，講清楚是遊戲裡的設定，不是 iPhone 系統的設定。
23. 這份還沒有泰文母語者校對（跟用詞表一樣），最需要校的是 24 種牛的介紹和新聞。
